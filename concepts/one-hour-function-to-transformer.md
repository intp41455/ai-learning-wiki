## 第 01 集：从函数到神经网络（00:00 - 09:28）

### 核心信念
> "你要相信这个世界上的所有逻辑和知识都可以用一个函数来表示。"

### 符号主义 AI
- 早期思路：把现实世界抽象为符号，设置运算规则（函数），算出结果反过来解释现实
- 例子：勾股定理（输入两直角边 → 输出斜边）、牛顿第二定律（输入质量+加速度 → 输出力）
- **问题**：很多问题人类想不出怎么写成一个明确的函数
  - 识别一张图片是否是猫：对人类简单，对计算机极难
  - 翻译：有明确语法规则尚且做不到足够丝滑，更别说复杂多变的智能

### 连接主义 AI
- 新思路：从简单例子入手，已知一些 X 和 Y，想找到 Y 和 X 的函数关系
- **核心方法**：猜 + 简化
  - 先随便猜一个函数（如 Y = wX + b，w=1, b=0）
  - 一点点调整 w 和 b，使直线越来越接近真实数据
  - 如果找不到完全吻合的函数，就"大差不差能进就行"
- 这种思想叫做**连接主义**：不再追求精确函数，而是寻找足够接近真实答案的近似解

### 为什么需要非线性激活函数
- 线性函数太简单，只能表示直线关系
- 需要在函数最外层套一个非线性函数（如平方、指数）
- **激活函数的目的**：把原本死气沉沉的线性关系变活了，变成变化能力更强的非线性关系
- 常见激活函数：Sigmoid、Tanh、ReLU（都简单到爆炸但效果很好）

### 从函数到神经网络
- 一个输入 x：线性变换 + 激活函数 = 一个神经元
- 多个输入：输入层变成多个神经元
- 多层叠加：每套一层相当于神经元水平方向又扩大一个
- **隐藏层**：中间层不再直接输出，而是包裹在复杂函数中，看不到
- **神经网络**：神经元互相连接形成的网络结构

### 前向传播
- 信号从左到右传播：输入层 → 隐藏层 → 输出层
- 每层：Z = W·X + b → A = g(Z)
- 本质：一点点分布式计算出一个函数值

### 关键洞察
> "估计你从函数到神经网络的这条路已经被你搞懂了。剩下的所有乱七八糟的知识都仅仅是为了算出这个 W 和 B 而已。"

## 第 02 集：计算神经网络的参数（09:10 - 20:06）

### 什么是好的 W 和 B
- 目标：让函数输出尽可能接近真实数据
- 好的 W/B = 使得函数输出尽可能拟合真实数据的那组参数

### 损失函数（Loss Function）
- 衡量预测值与真实值的差距
- 在每个数据点上画竖直线，长度 = 误差
- 把所有误差加起来 = 总差异 = 损失函数
- **均方误差（MSE）**：
  - 用平方代替绝对值（解决不光滑问题，放大误差影响）
  - 除以样本数量（消除样本量影响）
  - L = (1/n) · Σ(y - ŷ)²

### 求解 W 和 B
- 简单情况：让导数等于 0，求极值点
  - 例如：Y = wX，四个样本 1,2,3,4 → 展开损失函数 → 关于 w 的二次函数 → 求导得 w=1
- 复杂情况：神经网络参数多，无法直接求解析解

### 梯度下降
- 思路：一点点试，往让损失函数变小的方向调整
- 具体做法：
  1. 看当前 W/B 对损失函数的影响
  2. 每次往让损失变小的方向调整一点点
- **学习率（η）**：控制调整快慢的系数
- **梯度**：偏导数构成的向量，指向损失增长最快的方向
- **梯度下降**：让 W/B 往梯度的反方向变化
  - w = w - η · ∂L/∂w
  - b = b - η · ∂L/∂b

### 链式法则与反向传播
- 神经网络整体函数很复杂，但层与层之间的关系简单
- 求 L 对 W₁ 的偏导：
  - L 对 Y 的偏导 × Y 对 A 的偏导 × A 对 W₁ 的偏导
  - 链式相乘 = 偏导数
- **反向传播**：从右向左逐层求导，逐步更新每层参数
  - 前向传播：根据输入 X 计算输出 Y
  - 反向传播：计算损失函数关于每个参数的梯度
  - 每个参数往梯度反方向调整一点点
  - 构成一次训练迭代

### 训练过程
- 前向传播 → 计算损失 → 反向传播 → 更新参数
- 多轮训练，参数逐渐变化，直到损失函数足够小

## 第 03 集：调教神经网络的方法（20:06 - 28:00）

### 过拟合 vs 欠拟合
- **欠拟合**：模型太简单，训练集表现就差
- **过拟合**：模型太复杂，训练集表现好，测试集差
  - 在训练数据上表现完美，但没见过的数据表现糟糕
  - 泛化能力差

### 防止过拟合的方法

#### 1. 增加数据量
- 数据越多，复杂模型相对变简单
- **数据增强**：对现有数据进行变换（旋转、翻转、裁剪、加噪声），创造更多训练样本

#### 2. 简化模型
- 用更简单的模型（如线性模型）可能比复杂神经网络效果更好
- 神经网络不是越大越好

#### 3. 提前终止训练
- 差不多就行了，不用训练到完美
- 太粗暴，但有效

#### 4. 正则化（L1 / L2）
- 在损失函数中加入参数惩罚项
- **L1 正则化**：参数绝对值之和（L1 范数）
- **L2 正则化**：参数平方和（L2 范数）
- 抑制参数野蛮增长，防止过拟合
- **正则化系数**：控制惩罚力度的超参数

#### 5. Dropout
- 训练时随机丢弃一部分参数
- 类比：神经网络是一支军队，混入了一个战斗力极强的"闪客"
  - 如果每次训练都有闪客主导，会误认为整体战斗力很强
  - 随机丢弃闪客，让模型学会依赖更多普通士兵
- 方法简单到令人发指，但效果显著
- 由深度学习大师 Hinton 提出

### 其他训练问题
- **梯度消失**：网络越深，梯度越小，参数更新困难
- **梯度爆炸**：梯度数值越来越大，参数调整幅度失控
- **收敛过慢**：可能陷入局部最优或来回震荡
- **计算开销过大**：数据规模庞大，每次前向/反向传播耗时

### 解决方案
- 梯度裁剪：防止梯度爆炸
- 残差网络（ResNet）：防止深层网络梯度衰减
- 权重初始化 + 数据归一化：让梯度分布更平坦
- 动量（Momentum）、Adam 等优化器：加速收敛、减少震荡
- Mini-batch：把数据分割成小批次，降低单次计算量

### 关键洞察
> "深度学习的确像是一门玄学。正是由于出现了各种各样的困境，人们才想出各种五花八门的应对策略。"

## 第 04 集：从矩阵到 CNN（28:00 - 36:15）

### 为什么需要矩阵表示
- 神经网络写成一堆公式太麻烦
- 用矩阵运算可以：
  1. 公式更简单抽象，便于讨论更深问题
  2. 充分利用 GPU 并行计算，加速训练和推理

### 全连接层的问题
- 30×30 灰度图像 → 展开 900 个神经元 → 下一层 1000 神经元 → 参数量 90 万
- 大图像 224×224 → 全连接层参数量可达上亿
- 无法保留像素之间的空间关系（平移/变暗会完全改变输入）

### 卷积层
- 从图像中取一个小矩阵（如 3×3），再取一个固定矩阵（卷积核）
- 对应位置相乘并求和 = 卷积运算
- 卷积核在图像上滑动，得到新图像（特征图）
- **卷积核的值是未知的，通过训练学习**

### 卷积的优势
- 参数共享：同一卷积核用在整个图像上
- 局部连接：每次只看一个小区域
- 参数量大大减少
- 能有效捕捉局部特征（边缘、纹理等）

### 池化层
- 对特征图进行降维
- Max Pooling：取区域最大值
- Average Pooling：取区域平均值
- 作用：减少计算量，保留主要特征

### CNN 整体结构
- 卷积层 → 激活函数 → 池化层 → 重复 → 全连接层 → 输出
- 经典架构：LeNet → AlexNet → VGG → ResNet

### 关键洞察
> "我们把神经网络结构再次抽象了一个层次。原来画的各种小圈圈，在更高的视角下其实就是全连接层而已。"

## 第 05 集：从 RNN 到 Transformer（36:15 - 46:30）

### 词嵌入（Word Embedding）
- 把词从离散 ID 变成连续向量
- **One-Hot 编码**：只有一个位置为 1，其余为 0
  - 缺点：维度太高（词表 10 万 = 10 万维），词之间无法衡量相关性
- **词嵌入**：维度不高不低，训练出来的向量
  - 语义相近的词，向量距离也近
  - 经典例子：king - man + woman ≈ queen
- **嵌入矩阵**：所有词向量组成的大矩阵
- **词空间**：高维向量所在的空间，可通过距离/余弦相似度计算相关性

### 序列数据的挑战
- 文本长度可变，词序重要
- 经典神经网络无法表达词的先后顺序

### RNN（循环神经网络）
- 增加一个隐藏状态 h，在词与词之间传递
- 每个时间步：h_t = f(h_{t-1}, x_t)
- 前面的词的信息通过隐藏状态传递到后面的词

### RNN 的问题
- **梯度消失/爆炸**：信息随时间步增多而逐渐丢失，无法捕捉长期依赖
- **顺序计算**：必须按顺序处理，无法并行

### LSTM / GRU
- 门控机制：输入门、遗忘门、输出门
- 选择性记忆：遗忘门决定丢弃什么，输入门决定记住什么
- 缓解梯度消失，但仍有顺序依赖

### 从 RNN 到 Transformer 的必然性
- RNN：顺序处理，无法并行，长距离依赖弱
- Transformer：全局注意力，完全并行，长距离依赖强
- 大数据时代，计算效率决定上限

## 第 06 集：Transformer 简单而强大（46:30 - 56:40）

### Transformer 的核心创新
- 完全抛弃循环和卷积
- 只用 Self-Attention 处理序列
- 每一步都能看到整个序列

### 词嵌入 + 位置编码
- 词嵌入：每个词变成向量
- 位置编码：给每个词的位置加一个独特向量
  - Attention 本身是排列不变的（shuffle 输入，输出不变）
  - 但词序很重要！
  - 原始方案：正弦/余弦函数
    - PE(pos, 2i) = sin(pos / 10000^(2i/d))
    - PE(pos, 2i+1) = cos(pos / 10000^(2i/d))
  - 优点：可外推到更长序列

### Self-Attention 详解
- 每个词生成三个向量：Query、Key、Value
- **Q（Query）**：当前词"想问什么" → "我和谁相关？"
- **K（Key）**：每个词"能回答什么" → "我能被谁关注？"
- **V（Value）**：每个词"实际提供的信息" → "我提供什么信息？"
- **计算过程**：
  1. Q₁ 和 K₂ 做点积 → 第一个词和第二个词的相似度
  2. Q₁ 依次和所有 K 做点积 → 相似度矩阵
  3. Softmax → 归一化为权重
  4. 权重 × V 向量 → 加权求和 → A₁
- **A₁ 的含义**：在第一个词的视角下，按照相似度权重，把所有词的词向量加在一起
- 最终结果：每个词都包含了其他词的上下文信息

### 为什么除以 √d_k
- 防止点积过大 → Softmax 饱和 → 梯度消失
- 保证方差稳定在 1

### Multi-Head Attention（多头注意力）
- 一个词计算一组 Q/K/V → 再经过两个权重矩阵变成两组 Q/K/V
- 每组称为一个"头"（Head）
- 每个头独立做注意力，学习到不同的相关性模式
- 把头的结果拼接起来，再经过一次线性变换
- 类比：h 个专家从不同角度分析同一份材料

### Encoder-Decoder 架构

#### Encoder（编码器）
- 输入：要翻译的文本（如 "I love you baby"）
- 步骤：
  1. 词嵌入 → 词向量矩阵
  2. 加位置编码
  3. 多头注意力 → 残差连接 → LayerNorm
  4. 前馈神经网络 → 残差连接 → LayerNorm
  5. 输出：包含上下文信息的中间表示

#### Decoder（解码器）
- 输入：已翻译的部分（如 "我"）
- 步骤：
  1. 词嵌入 → 位置编码
  2. **掩码多头注意力**（只能看过去的词）
  3. 残差连接 → LayerNorm
  4. **交叉注意力**：Q 来自 Decoder，K/V 来自 Encoder
  5. 前馈神经网络 → 残差连接 → LayerNorm
  6. 线性变换 → Softmax → 预测下一个词的概率分布

### Masked Attention（掩码注意力）
- 训练时模拟真实推理场景
- 翻译时是一个词一个词翻译的，不能偷看后面的词
- 用掩码把后面的词遮挡住

### 关键洞察
> "Transformer 确实是个特别简单的架构。原文中也是这样说的。尤其是当你有了基础的神经网络知识之后，如果你看了这个系列之前的视频，那就只有多头注意力这一层是陌生的。"

## 第 07 集：速通大模型 100 词（56:40 - 69:00+）

### 核心术语

| 术语 | 含义 | 闪客原理解释 |
|------|------|------------|
| Token | 文本最小处理单元 | 不一定是完整词，可能是词片段 |
| Embedding | 词 → 向量 | 语义相近的词，向量距离也近 |
| 上下文（Context） | 对话时所有给模型的信息 | 相当于人的短期记忆容量 |
| Context Window | 模型一次处理的最大长度 | 越大越能记住前面的信息 |
| Temperature | 生成时的随机性控制 | 高 = 更有创意，低 = 更确定 |
| Top-p / Top-k | 采样策略 | 控制生成多样性 |
| Fine-tuning | 微调 | 在预训练基础上继续训练特定任务 |
| RLHF | 人类反馈强化学习 | 让模型输出更符合人类偏好 |
| Prompt Engineering | 提示词工程 | 通过 prompt 引导模型输出 |
| RAG | 检索增强生成 | 先检索相关知识库，再生成回答 |
| Agent | 自主智能体 | 能规划、使用工具、执行任务 |
| 涌现（Emergence） | 量变引起质变 | 参数足够大时，突然出现之前没有的能力 |
| 闭源模型 | 不开放代码和权重 | 如 ChatGPT、Claude、文心一言 |
| 开源模型 | 开放权重 | 如 Llama、DeepSeek（实际是开放权重模型） |
| 私有化部署 | 下载到本地使用 | 需要 GPU 和环境配置 |
| AIGC | AI 生成内容 | 由 AI 创作或辅助创作的内容 |
| AGI | 通用人工智能 | 人们对于 AI 最终形态的畅想 |
| 多模态 | 处理多种形式内容 | 文本、图片、声音、视频等 |
| 工作流 | 多个步骤编排成流程 | 如扣子、LangChain |
| MCP | 模型上下文协议 | AI 操作外部工具的统一标准 |
| 蒸馏 | 大模型指导小模型 | 用大模型的知识提升小模型 |
| 量化 | 降低数值精度 | 减少显存和计算量 |
| 卖铲子 | AI 周边产品 | 在 AI 淘金热中帮助别人淘金 |

### 关键洞察
> "AI 时代瞬息万变，产品工具层出不穷，但它的技术及作用依然保持不变。从最底层的线性代数、微积分、最优化，到深度学习用神经网络表示函数，用损失函数最小化为目标，通过反向传播训练参数。再到 Transformer 架构，他们共同撑起了现代 AI 技术的大厦。"

## 闪客讲解风格总结

1. **大白话类比**：把数学概念翻译成生活直觉
2. **动画可视化**：用动态图示展示数据流动
3. **从问题出发**：先讲旧方案为什么不行，再引出新方案的必然性
4. **系列递进**：每一集都是下一集的前置知识
5. **自嘲幽默**：自称"傻客"，自称"玄学"，降低学习门槛
6. **抓大放小**：重点讲核心思想，细节留给感兴趣的人深挖
