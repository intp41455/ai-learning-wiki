mindmap
  root((Python变量交换))
    问题引入
      需求：A=10 B=20 → A=20 B=10
      直觉错误思路
        A=B; B=A
        结果：A和B都变成20
    正确解法
      引入临时变量C
      三步交换法
        C=A（保存A的原始值）
        A=B（A获得B的值）
        B=C（B获得A的原始值）
    生活类比
      两个杯子交换饮料
      需要第三个空杯
    代码实现
      基础版：两步变量交换
      练习：三变量循环交换
    核心考点
      变量是数据容器
      直接赋值会覆盖
      临时变量保存被覆盖的值
      易错：A=B; B=A无效
