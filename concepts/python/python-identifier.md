# Python 标识符

> 一句话：标识符是**开发人员在代码中给各类元素起的名字**。

#python/basics #python/naming

## 定义拆解

| 要素 | 说明 |
|------|------|
| 定义主体 | 代码开发人员 |
| 应用场景 | 在代码中给各类元素命名 |
| 命名覆盖范围 | 变量、函数、类 |

- 当前阶段已接触：**变量**
- 后续课程学习：函数、类

## 现阶段简化理解

初学者可以直接把标识符理解为「**变量的名字**」。函数、类的命名规则后续会讲，底层与标识符规则一致。

## 规则性质

标识符命名规则是 Python 的**硬性规定**，必须严格遵守，违反会导致代码报错、无法运行。

> 规则 ≠ 规范。规则违反会报错，规范（见 [[pep8-style-guide]]）不遵守只是不优雅。
