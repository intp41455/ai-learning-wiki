# 动态索引（Dataview）

> 需要 **Dataview 插件**（已安装启用）。查询随笔记自动更新，不用手动维护。

## 全部笔记

```dataview
TABLE title AS 标题, type AS 类型, updated AS 更新, tags AS 标签
FROM !"copilot"
WHERE type != null
SORT updated DESC
```

## Python 主题

```dataview
TABLE title AS 标题, type AS 类型, updated AS 更新
FROM #python
SORT updated DESC
```

## AI / 机器学习主题

```dataview
TABLE title AS 标题, type AS 类型, updated AS 更新
FROM #ai OR #machine-learning OR #deep-learning OR #llm
SORT updated DESC
```

## 可视化资产（导图 / 图谱）

```dataview
TABLE title AS 标题, type AS 类型, updated AS 更新
FROM !"copilot"
WHERE type = "mindmap" OR type = "graph"
SORT type ASC
```
