## 第 01 集：从函数到神经网络

大家好，我是傻克，这里是用大白话搞懂的第一期。

**核心信念**：你要相信这个世界上的所有逻辑和知识都可以用一个函数来表示。

### 符号主义 AI
- 早期思路：把现实世界抽象为符号，设置运算规则（函数），算出结果反过来解释现实
- 例子：勾股定理（输入两直角边 → 输出斜边）、牛顿第二定律（输入质量+加速度 → 输出力）
- 这就是人工智能早期的思路：符号主义

### 连接主义的诞生
- 问题：很多问题人类想不出怎么写成一个明确的函数
- 例子：识别一张图片是否是猫，对人类简单爆炸，对计算机是世纪难题
- 新思路：先随便猜一个函数，然后一点点调整参数使结果接近真实数据
- **连接主义**：不再追求精确函数，而是通过简化函数并寻找足够接近真实答案的近似解

### 从线性到非线性
- 线性函数太简单，只能表示直线关系
- 需要在函数最外层套一个非线性激活函数（如平方、指数）
- 激活函数把线性关系变活，变成变化能力更强的非线性关系

### 神经网络的结构
- 一个输入 x：线性变换 + 激活函数 = 一个神经元
- 多个输入：输入层变成多个神经元
- 多层叠加：每套一层相当于神经元水平方向又扩大一个
- **隐藏层**：中间层不再直接输出，而是包裹在复杂函数中
- **神经网络**：神经元互相连接形成的网络结构

### 前向传播
- 信号从左到右传播：输入层 → 隐藏层 → 输出层
- 每层：Z = W·X + b → A = g(Z)
- 本质：一点点分布式计算出一个函数值

## 第 02 集：计算神经网络的参数

### 损失函数
- 衡量预测值与真实值的差距
- 在每个数据点上画竖直线，长度 = 误差
- 把所有误差加起来 = 总差异
- **均方误差（MSE）**：
  - 用平方代替绝对值（解决不光滑问题，放大误差影响）
  - 除以样本数量（消除样本量影响）
  - L = (1/n) · Σ(y - ŷ)²

### 梯度下降
- 思路：一点点试，往让损失函数变小的方向调整
- 每次看当前状况，调整 W 和 B 对损失函数的影响
- 每次往让损失变小的方向调整一点点
- **学习率（η）**：控制调整快慢的系数
- **梯度**：偏导数构成的向量，指向损失增长最快的方向
- **梯度下降**：让 W/B 往梯度的反方向变化

### 反向传播
- 链式法则的高效实现
- 从输出层往输入层逐层计算梯度
- 前向传播：根据输入 X 计算输出 Y
- 反向传播：计算损失函数关于每个参数的梯度
- 每个参数往梯度反方向调整一点点
- 不断前向传播、反向传播 = 神经网络的训练过程

## 第 03 集：调教神经网络的方法

### 过拟合 vs 欠拟合
- **欠拟合**：模型太简单，训练集表现差
- **过拟合**：模型太复杂，训练集好测试集差
  - 在训练数据上表现完美，但没见过的数据表现糟糕
  - 泛化能力差

### 防止过拟合
1. **增加数据量**：数据越多，复杂模型相对变简单
   - 数据增强：旋转、翻转、裁剪、加噪声
2. **简化模型**：用更简单的模型可能比复杂神经网络效果更好
3. **提前终止训练**：差不多就行了
4. **正则化（L1/L2）**：在损失函数中加入参数惩罚项
   - L1：参数绝对值之和
   - L2：参数平方和
   - 正则化系数：控制惩罚力度
5. **Dropout**：训练时随机丢弃一部分参数
   - 让模型学会依赖更多参数，避免过度依赖少数参数

### 其他问题
- 梯度消失、梯度爆炸、收敛过慢、计算开销过大
- 解决方案：梯度裁剪、残差网络、权重初始化、数据归一化、优化器、Mini-batch

## 第 04 集：从矩阵到 CNN

### 矩阵运算的必要性
- 神经网络写成一堆公式太麻烦
- 矩阵运算：公式更简单，充分利用 GPU 并行计算

### 全连接层的问题
- 30×30 图像 → 900 个神经元 → 下一层 1000 神经元 → 参数量 90 万
- 无法保留像素之间的空间关系

### 卷积层
- 取一个小矩阵（3×3），再取一个固定矩阵（卷积核）
- 对应位置相乘并求和 = 卷积运算
- 卷积核在图像上滑动，得到特征图
- 卷积核的值通过训练学习

### 卷积的优势
- 参数共享：同一卷积核用在整个图像上
- 局部连接：每次只看一个小区域
- 参数量大大减少
- 能有效捕捉局部特征

### CNN 整体结构
- 卷积层 → 激活函数 → 池化层 → 重复 → 全连接层 → 输出
- 经典架构：LeNet → AlexNet → VGG → ResNet

## 第 05 集：从 RNN 到 Transformer

### 词嵌入
- 把词从离散 ID 变成连续向量
- One-Hot 编码：只有一个位置为 1，其余为 0
  - 缺点：维度太高，词之间无法衡量相关性
- 词嵌入：维度不高不低，训练出来的向量
  - 语义相近的词，向量距离也近
  - king - man + woman ≈ queen
- 嵌入矩阵：所有词向量组成的大矩阵
- 词空间：高维向量所在的空间

### RNN
- 增加一个隐藏状态 h，在词与词之间传递
- 每个时间步：h_t = f(h_{t-1}, x_t)
- 前面的词的信息通过隐藏状态传递到后面的词

### RNN 的问题
- 梯度消失/爆炸：信息随时间步增多而逐渐丢失
- 顺序计算：必须按顺序处理，无法并行

### LSTM / GRU
- 门控机制：输入门、遗忘门、输出门
- 选择性记忆，缓解梯度消失，但仍有顺序依赖

### 从 RNN 到 Transformer
- RNN：顺序处理，无法并行，长距离依赖弱
- Transformer：全局注意力，完全并行，长距离依赖强

## 第 06 集：Transformer 简单而强大

### 词嵌入 + 位置编码
- 词嵌入：每个词变成向量
- 位置编码：给每个词的位置加一个独特向量
  - Attention 本身是排列不变的
  - 但词序很重要！
  - 原始方案：正弦/余弦函数
    - PE(pos, 2i) = sin(pos / 10000^(2i/d))
    - PE(pos, 2i+1) = cos(pos / 10000^(2i/d))

### Self-Attention
- 每个词生成三个向量：Query、Key、Value
- Q（Query）：当前词"想问什么" → "我和谁相关？"
- K（Key）：每个词"能回答什么" → "我能被谁关注？"
- V（Value）：每个词"实际提供的信息" → "我提供什么信息？"
- 计算：Attention(Q, K, V) = softmax(QK^T / √d_k) · V

### Multi-Head Attention
- 一个词计算一组 Q/K/V → 再经过两个权重矩阵变成两组
- 每组称为一个"头"
- 每个头独立做注意力，学习到不同的相关性模式
- 把头的结果拼接起来，再经过一次线性变换

### Encoder-Decoder
- **Encoder**：词嵌入 → 位置编码 → 多头注意力 → 残差连接 → LayerNorm → 前馈网络 → 残差连接 → LayerNorm
- **Decoder**：词嵌入 → 位置编码 → 掩码多头注意力 → 残差连接 → LayerNorm → 交叉注意力（Q来自Decoder，K/V来自Encoder） → 前馈网络 → 线性变换 → Softmax

### Masked Attention
- 训练时模拟真实推理场景
- 翻译时是一个词一个词翻译的，不能偷看后面的词
- 用掩码把后面的词遮挡住
